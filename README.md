Customer churn is an important problem for banks because losing an existing customer can reduce customer lifetime value, increase customer acquisition costs, and create revenue instability.

The main business questions I wanted to answer were:

Which customers are leaving the bank?

Which countries have the highest churn?

Which age groups are more vulnerable?

Does customer activity affect churn?

Are high-value customers also leaving?

And what financial exposure is associated with churned customers?

My project attempts to answer these questions using exploratory data analysis and customer segmentation.
